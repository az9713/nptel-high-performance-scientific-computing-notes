Learning route and prerequisites

Start with C programming, elementary linear algebra and calculus, and a working Linux shell (native Linux or WSL 2 on Windows). Chapter 9 uses finite differences for the Laplace equation. The chapter programs are C, Python 3 and Bash; they need gcc with OpenMP support, and the Python programs of chapters 1, 4 and 9 also need NumPy.

  1. Purpose and the Linux environment, chapters 1–5: what scientific computing needs from hardware, the operating system and kernel, the file system and its permissions, processes, text tools, memory and networking commands, and shell scripts.
  2. Hardware, memory and concurrency, chapters 6–8: the components of an HPC system and a compute node, the memory hierarchy and scalable architectures, and races, locks, atomic instructions and barriers.
  3. Why parallel, and what limits it, chapters 9–10: the cost of a numerical model (the serial Jacobi solver used as the running example), speedup laws, memory bottlenecks, the organization of large systems and the Grace Hopper superchip.
  4. Shared-memory programming, chapter 11: OpenMP threads, parallel regions and the distribution of work.
  5. Not yet written, chapters 12–31: OpenMP II–III, MPI, domain decomposition, GPU architecture and CUDA, OpenACC, multi-device programs, profiling and debugging, numerical libraries, batch schedulers and visualization, and heterogeneous computing.

Read the chapters in order, then work through the expandable solutions and reproduce the chapter programs. The source map separates lecture material, research extensions, and original teaching constructions.
