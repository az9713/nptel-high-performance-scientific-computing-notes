Code laboratory

Reproduce the programs already developed in the chapters: system calls and processes, file permissions, shell scripts, memory-hierarchy and bandwidth probes, races and locks, the Jacobi solver, and OpenMP synchronization, scheduling, reductions and data sharing.

This laboratory is a directory and command-line launcher for the existing chapter programs. Read each chapter for its assumptions, model definitions, units, and worked interpretation.

Download the Python launcher with the rest of the repository. The programs are C, Python 3 and Bash, and run in a Linux shell: natively on Linux, or through WSL 2 on Windows. They need gcc with OpenMP support, and the Python programs of chapters 1, 4 and 9 also need NumPy. From the repository root:

python code_lab.py
python code_lab.py --chapter 9
python tools/check_chapter_code.py

The first command lists the programs of each chapter. The second builds and runs every program of one chapter in a temporary directory. The verification tool runs all programs and compares their output with the printed output in the book: byte for byte where a listing is marked data-check="exact", and successful exit only where it is marked data-check="returncode" (timings and thread interleaving differ from run to run). The execution record reports actual results on the verification machine.
